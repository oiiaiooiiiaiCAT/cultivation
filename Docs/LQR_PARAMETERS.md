# 当前 LQR 参数与平衡角标定

## 角度基准

- 前倾 Pitch 增大，后仰减小。传感器安装补偿保持 `MPU6050_PITCH_OFFSET_DEG=5.0f`，不因修改平衡角而改变。
- 用户观察原 OLED 整数 Pitch：约 +4 时后仰，约 +5 时前倾，原先取中间值 +4.5°；用户反馈约0.7 m范围内往复移动后，先按要求将参考下调到+4.1°，后由用户改为+3.7°；保留该最新值，尚不能认为位置振荡已解决。
- `LQR_BALANCE_PITCH_DEG=3.7f` 初始化 `g_lqr.balancePitchDeg`。LQR 使用 `(pitchDeg-balancePitchDeg)*pi/180`，不是把 OLED 或融合角整体归零。
- 安装补偿、平衡参考不是两个要叠加到传感器上的修正。不要再把安装补偿增加或减少4.1°，否则会改变已标定的坐标基准。
- 位置换算仍使用原校正 Pitch，角速度不减常数。固定角度零点只给位置增加常量，位置参考会在失能和首次使能时对齐；不要把相对平衡角的偏差再传给 `LQR_Update()`，避免重复减参考。

## OLED 与 Watch

保持三页，SELECT 切换：

- 状态页第二行例：`P:+003.7E:+000.0`。`P` 为校正后 Pitch，`E=P-balancePitchDeg`，一位小数。
- MPU 页首行 `REF:+003.7 deg`，随后为 Pitch、Yaw、Roll，均为一位小数。符号和宽度固定，跨零时不会留下旧数字。
- 手柄页不变。超出显示范围或非有限角度显示 `ERROR`，不改变使能状态。
- Watch：`g_lqr.balancePitchDeg`（deg）、`g_lqr.state[2]`（误差rad）、`g_lqr.rawCurrentA`（未限幅A）、`g_lqr.currentMa`（限幅mA）、`g_car.targetL/targetR`（混合航向PID后的轮电流）。

当位置误差、速度、角速度均为0时，Pitch=3.7°应得到0 A；默认1.0倍输出下，3.2°的倾角项约为-11 mA，4.2°约为+11 mA。实际输出还包含其他三个状态，不能只凭总电流判断倾角符号。

## 机械模型

| 项目 | 当前值或处理 |
| --- | --- |
| 整车质量 | 1.0415 kg，以整车称重为准 |
| 上/下部分质量 | 约0.3385/0.693 kg，两者刚性固定一起俯仰 |
| 分部称重差异 | 两者相加比整车少0.010 kg，尚未分配，不据此更改总质量 |
| 两轮质量 | 约0.100 kg，不是整个下半部质量 |
| 俯仰车体质量 | 1.0415-0.100=0.9415 kg，包含固定电机外壳、底座、上部 |
| 轮半径 | 0.0335 m，直驱 |
| 整车质心坐标 | x=-0.010 m、z=+0.01644 m，向前/向上为正 |
| 整车质心到轴距离 | sqrt(0.010²+0.01644²)=0.01924249 m |
| 车体质心到轴距离 | 假设轮子合成质心在轴线，乘整车/车体质量比，约0.02128631 m |
| 车体自身质心俯仰惯量 | 沿用估计0.0015 kg·m²，未实测 |
| 轮侧惯量 | 0.5*0.100*r²+2*4.8e-6 kg·m²，轮子近似均匀圆盘并加两转子惯量 |
| 单电机转矩常数 | 沿用0.43/2=0.215 N·m/A估计，实际动态关系未验证 |

质心坐标若是在同一个 Pitch=0 姿态测得，会推算还需前倾31.31°，与 +3.7° 的平衡观察不一致。测量时姿态尚未对齐，所以只暂取坐标的径向长度来估算平衡点处的车体质心高度，角度参考独立采用实测观察。不能宣称几何模型已经校准，应重新测量质心、核对轴线和测量姿态。电机转子与车体质量的细分、轮胎惯量、驱动电流与力矩也仍是近似。

## 增益与验证

离线脚本为工作区 `Docs/calculate_lqr.py`（相对本仓库为 `../Docs/calculate_lqr.py`）。在工作区根目录运行：

```text
python Docs/calculate_lqr.py
```

输入为两轮共同的单轮电流A，不是总电流，不再除以2。周期4 ms，`Q=diag(2,0.5,80,0.5)`、`R=100` 不变。围绕平衡点的状态为 `[位置误差m, 速度m/s, Pitch误差rad, Pitch角速度rad/s]`。

```text
K = [-0.12917357, -0.27696665, -1.26644399, -0.11257765]
currentA = outputScale * (-K * state)
```

脚本检查可控性、Riccati残差、标称闭环极点、源码增益、周期、轮半径和平衡参考。它不会自动写入固件；修改模型后须同步K。电流现限幅±1500 mA，再与航向PID混合，保留平衡电流余量和原方向映射。

### 2.5倍输出实验（历史，当前默认已退回1.0）

以下记录2.5倍实验和数值检查，不是当前默认参数。用户反馈纠正猛烈、需手压抑制后，当前宏已退回1.0；+3.7°平衡参考和±1500 mA上限保留。

用户反馈纠偏慢，要求输出力度改为原来的2.5倍。新增 `LQR_OUTPUT_SCALE=2.5f` 初始化 `g_lqr.outputScale`；原离线K保留，计算结果统一乘倍率再限幅。`rawCurrentA`改为倍率生效后、限幅前的电流。Watch设为1恢复旧力度，复位恢复宏默认值；0只取消LQR分量，不能代替停机，因为航向PID仍可能驱动两轮。倍率必须有限且非负，异常时本轮LQR返回无效并输出零，不自动切换使能。

这使未饱和的相同状态获得2.5倍电流请求，不是车速、响应时间或控制频率提高2.5倍，倍率本身不改变限流，当前限流已另行提高至±1500 mA。进入限幅后倍率不再提供成比例的实际输出，航向PID仍按剩余电流空间混合。不能同时再将四个gain乘2.5，否则会重复放大。

未考虑传感器/驱动延迟的标称模型下，2.5倍闭环极点约为0.6167083、0.9530609、0.9982661±0.0019353j，均在单位圆内；但位置慢模态模长比1倍时更靠近1，没有按2.5倍加快。脚本同时检查原K和倍率后的标称极点。全量倍增不是重新优化Q/R得到的LQR，不能承诺改善位置往返，更不能作为实车稳定性证明。

仍需确认参考位置不漂移、位置/速度反馈方向和时效，受控观察饱和标志。若往返增大或抖动明显，停止输出并退回1倍，不继续通过增大倍率追求纠偏速度。保持原START语义，无新增自动停机，必须准备物理断电。

MPU加速度为±4 g、8192 LSB/g，陀螺仪保持±2000°/s、16.4 LSB/(°/s)。量程与工程量换算成对配置；加速度范围按每轴、包含重力分量及冲击考虑，不能只看车轮平移加速度。

## 实车调试边界

1. 先失能观察：在认为接近平衡的位置查看小数Pitch，不再从整数4/5反推精确角度；必要时只微调 `g_lqr.balancePitchDeg`，确认误差跨零。
2. 验证静止姿态、陀螺零偏、反馈更新时间和电机方向。平衡参考只校正角度，不补偿陀螺零偏，也不能修复电机符号错误。
3. 架空并固定车体时只验证方向、通信和停止；地面平衡性能需在限制倾倒、位移的支架上单独验证。保持物理断电可用。
4. 保留START手动调参模式，新增启动校准成功才能使能的门槛，没有新增自动启动、运行期自动停机或故障锁存；陈旧反馈、手柄失联和CAN发送失败仍可能继续驱动。非有限计算结果输出零电流不等于硬件已停机。
5. Watch微调不持久化，复位恢复宏默认值；确认参考后更新 `LQR_BALANCE_PITCH_DEG`、脚本中的参考校验和本文档。

数学验证和编译通过不能代替实车验证。本次不自动下载或启动电机。

## 上电陀螺仪零偏校准

### 启动阻塞修复

初版接入时，校准前的停机路径 `Car_Init→Car_StopMotors→Motor_StopPair→MotorBus_CancelPending` 使用了 FreeRTOS 的任务临界区。Cortex-M3端口在调度器启动前的临界嵌套初值非0，退出后仍保留BASEPRI屏蔽；本工程TIM1 HAL时基中断优先级15，因而HAL_GetTick不再递增，后续MPU复位中的HAL_Delay(100)或校准延时无法结束。这不是多次静止检查失败造成的等待。

`MotorBus_CancelPending` 和同类 `Motor_ResetFeedback` 已改为保存PRIMASK、短暂关中断、恢复原PRIMASK，不修改内核临界嵌套或BASEPRI。原本已关中断的调用者也不会被错误打开中断；CAN发送、等待、HAL延时均保持在临界区之外。启动时不要在调度器启动前调用其他任务临界区，也不要靠提高HAL时基优先级掩盖这个问题。

OLED启动阶段依次区分 `IMU INIT...`、`STABILIZING...`、`CALIBRATING...`。若仍停留，记录第三行和TRY次数以定位具体阶段；正常采样有次数上限，整个启动过程不应无限等待。

### 校准流程和判据

原驱动虽然有 `MPU6050_CalibrateGyro()`，启动流程并没有调用，导致 `gyroBias` 一直为0。本次将校准接入调度器启动前的 `Car_Init()`；姿态融合、俯仰角速度和航向角速度原本就会减去该零偏，不再重复扣除或重置平衡角。

启动流程：请求两轮停机/失能，配置MPU，等待1000 ms，再以5 ms间隔采样500次，通常约2.5秒加读取耗时。OLED提示 `KEEP CAR STILL` 和尝试次数。最多3次采样窗口，避免无限等待。上电总耗时还包括原有1秒等待及外设初始化。

校准要求固定静止、没有明显振动；不要求水平，倾斜支架上也可以。三轴角速度均值作为零偏，仅全部检查通过才一次性提交。不会把当前加速度角当作零度，也不会更改安装补偿+5°或平衡参考+3.7°。仅保存RAM，不写Flash，每次复位重测。

静止质量检查均可在 `Hardware/mpu6050.h` 调整，当前起始阈值为：

| 检查项 | 默认 |
| --- | --- |
| 每轴角速度样本标准差 | 不超过0.35°/s |
| 每轴角速度峰峰值 | 不超过2.0°/s |
| 每轴角速度绝对值 | 不超过20°/s |
| 每轴加速度样本标准差 | 不超过0.02 g |
| 每个样本三轴加速度模长 | 0.85～1.15 g |
| 读取完整性 | 每次读取均成功、各轴均为有限数 |

这些检查只能降低把运动学成零偏的风险，不能证明绝对静止，尤其无法可靠区分慢速匀速绕重力方向旋转。因此校准时必须人为固定车体。若固定后仍失败，应检查供电、接线、振动和实际噪声，不能直接盲目放宽阈值。

Watch观察 `g_mpu6050.gyroCalibrated`、`gyroBias[0..2]` 和 `gyro_dps[axis]-gyroBias[axis]`。`gyro_dps`仍然是原始工程量，不要因校准后该变量不为0而误判失败。`initialized`只表示寄存器配置及身份检查，`healthy`只表示最近姿态读取成功，不能代替校准标志。

运动检查失败返回 `HAL_BUSY`，参数、非有限数或读取失败返回 `HAL_ERROR`，成功返回 `HAL_OK`。失败不写入候选零偏，`gyroCalibrated=0`，START不允许使能；状态页显示 `IMU CAL FAILED`，固定后复位重试。运行期间没有自动重新学习零偏，避免把真实转动误当偏置，也没有新增自动停机。

这只校正启动时的陀螺静态偏置，不是加速度计六面校准或温度补偿。温度变化后的残余漂移仍需实测；航向仍是纯陀螺积分，没有绝对航向观测，不能保证长期不漂。若主要是Pitch变化，还需区分静态漂移、安装基准误差与运动加速度对融合倾角的影响。

## 软件限流提高到每轮1500 mA

用户已将驱动闭环最大电流设为4400 mA；截图及本地《ZDT_X42S第二代闭环步进电机用户手册V1.0.5_260527》第82页5.6.13说明X固件该设置为运行时电流上限，协议范围0～5000 mA；第51页5.3.3/5.3.4说明F5/C5命令电流单位直接为mA，符号与幅值分开，不是百分比或缩小10倍输入。

软件分阶段提高：`LQR_CURRENT_LIMIT_MA`由500改1500，`MOTOR_CURRENT_LIMIT_MA`由1000改1500；不自动发送0x45命令、不写驱动Flash，不把驱动4400设定当成软件目标或电机持续额定值。1500只是本次调试选择，不是经验证的持续安全电流。静态检查要求LQR上限不超过发送层，离线脚本也核对两级上限与协议范围。

两轮各自目标电流范围±1500 mA，不是两轮相加1500 mA。航向修正仍最多250 mA，并限制到1500-abs(LQR电流)余量；输出接口再次限幅。OLED I1/I2保留原布局，电流数字扩为四位，显示如I1:+1500I2:-1500。电流目标值、最近成功发送值不是实测电流。

观察`g_lqr.rawCurrentA`与`g_lqr.saturated`：新版超过±1.5 A请求才触发LQR限幅；如果此前请求始终小于±0.5 A，提高上限不改变同状态输出。当前输出倍率1.0；倍率始终在限流前生效，最终仍限制±1500 mA，不会再将限流上限乘倍率。驱动命令斜率仍65535 mA/s，实际响应不是瞬时；本次未改斜率。

这不是往返振荡根因已解决的结论，且目前没有应用层运行期自动停机。使用限制倾倒和位移的支架、物理断电，观察是否振荡加剧或长时间限幅；停止后再调整，不在自由地面反复试跑。

## 当前抖动排查：一次只回退整体倍率

用户报告电流放大及提高上限后纠正猛烈，手压抑制时表现改善，并已自行把平衡参考改为+3.7°。这提示整体输出过强、阻尼或反馈延迟等风险，但不能仅凭手扶现象确定根因；手扶同时改变受力、运动约束和振动。

本轮只把`LQR_OUTPUT_SCALE`从2.5退回1.0；用户的+3.7°不改，原K和两级1500 mA限流不改。未饱和同状态请求降至原2.5倍版本的40%；如果两版均饱和，实际命令不一定降低40%。不同时盲改角速度反馈、位置反馈、滤波或航向PID，避免失去对照。编译、标称极点和主机测试不代表实车稳定。

不要用手压正在抖动的车当作调参手段，使用限制倾倒和位移的支架。先失能核对+3.7°处的角度误差为0、传感器反馈方向正确；准备物理断电后仅进行受控观察。用Watch实时刷新而非暂停，观察state[0..3]、currentMa、saturated及反馈标志，并区分前后俯仰、左右偏航或高频结构振动。若仍有抖动，下一步需提供摆动方向、周期及这些变量，不能直接假定加大角速度增益一定能改善。当前无运行期自动停机。
